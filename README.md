# 酒店预订系统

## 项目简介

本项目是《软件工程原理与应用》课程设计项目，主要实现一个酒店预订系统。系统面向普通用户和管理员两类角色，支持酒店查询、预订、支付、收藏、评论和后台管理等功能。

## 项目成员

祝大珩、章可、苏文乔、陈静怡

## 主要功能

### 普通用户

- 注册、登录、修改个人信息
- 查询酒店信息
- 查看酒店详情
- 提交、修改、取消预订
- 查看订单状态
- 支付订单
- 收藏酒店
- 发布酒店评价

### 管理员

- 管理用户信息
- 添加、修改、删除酒店信息
- 审核预订订单
- 管理支付记录
- 审核和管理评论

## 系统模块

- 用户管理模块
- 酒店信息管理模块
- 预订管理模块
- 支付管理模块
- 收藏管理模块
- 评论管理模块
- 通知提醒模块
